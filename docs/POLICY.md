# 프로젝트 정책

## 반드시 지킬 원칙

1. 공개 저장소에 비밀값을 넣지 않는다.
2. 사용자의 개인정보와 민감한 데이터를 최소한으로 수집한다.
3. 삭제, 파기, 배포는 사람이 최종 확인한다.
4. AI 생성 결과는 필요한 경우 사람이 검토한다.
5. 작은 단위로 구현하고 검증한다.
6. 정책이나 구조를 바꾸면 관련 문서를 함께 갱신한다.

## 민감한 정보

다음 정보는 공개 문서와 커밋에 작성하지 않는다.

- API 키와 액세스 토큰
- 비밀번호와 개인키
- 서비스 계정 JSON
- 개인정보와 위치정보
- 사용자 사진과 운영 데이터
- 내부 서버 주소와 접속 정보

값이 필요한 문서에는 다음처럼 표시한다.

```text
[비밀값 입력 금지]
[GitHub Secrets에 등록]
[사용자 입력 필요]
```

- 접근 권한: [사용자 입력 필요]

## 배포와 복구

- 배포 전 테스트 결과를 확인한다.
- 롤백 방법을 문서화한다.
- 운영 데이터가 포함된 작업은 별도 승인 없이 실행하지 않는다.
