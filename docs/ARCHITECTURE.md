# 아키텍처 문서

## 현재 구조

```text
사용자
  ↓
[클라이언트: 사용자 입력 필요]
  ↓
[서버/API: 사용자 입력 필요]
  ↓
[데이터 저장소: 사용자 입력 필요]
  ↓
[외부 서비스/AI: 사용자 입력 필요]
```

## 구성요소

| 구성요소 | 역할 | 기술 | 비고 |
|---|---|---|---|
| 클라이언트 | 사용자 화면과 입력 | [사용자 입력 필요] | |
| 서버 | 인증·업무 로직·API | [사용자 입력 필요] | |
| 데이터 저장소 | 서비스 데이터 보관 | [사용자 입력 필요] | 개인정보 주의 |
| 외부 서비스 | [사용자 입력 필요] | [사용자 입력 필요] | 비밀값은 Secrets 사용 |

## 데이터 흐름

1. [사용자 입력 필요]

3. [사용자 입력 필요]

## 보안 경계

- 실제 비밀값은 코드와 문서에 기록하지 않는다.
- 사용자 데이터는 필요한 만큼만 수집한다.
- 로그에 토큰, 비밀번호, 원본 개인정보를 남기지 않는다.
- 운영 데이터와 테스트 데이터를 분리한다.
