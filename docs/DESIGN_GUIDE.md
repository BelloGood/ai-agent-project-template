# 디자인 가이드

## 기본 원칙

- 사용자가 한 화면에서 해야 할 일을 하나로 제한한다.
- 핵심 버튼은 쉽게 찾고 누를 수 있게 만든다.
- 오류가 발생했을 때 사용자가 복구 방법을 알 수 있게 한다.
- 장식보다 이해하기 쉬운 정보 전달을 우선한다.

## 시각 규칙

| 항목 | 기준 |
|---|---|
| 기본 글자 크기 | [사용자 입력 필요] |
| 주요 색상 | [사용자 입력 필요] |
| 버튼 최소 크기 | [사용자 입력 필요] |
| 모서리 반경 | [사용자 입력 필요] |
| 여백 | [사용자 입력 필요] |

## 접근성 확인

- [ ] 텍스트와 배경의 대비가 충분하다.
- [ ] 키보드 또는 보조기기로 핵심 기능을 사용할 수 있다.
- [ ] 색상만으로 상태를 구분하지 않는다.
- [ ] 로딩과 성공·실패 상태를 알 수 있다.
