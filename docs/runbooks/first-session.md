# 첫 세션 런북

새 AI 에이전트에게 프로젝트 작업을 맡길 때 사용하는 절차다.

## 1. 준비

- 저장소를 열고 `AGENTS.md`를 확인한다.
- `docs/INDEX.md`에서 관련 문서를 찾는다.
- 실제 비밀값이 대화나 파일에 포함되지 않았는지 확인한다.

## 2. 첫 요청 예시

> 이 저장소의 `AGENTS.md`, `docs/INDEX.md`, `docs/PRD.md`, `docs/POLICY.md`를 먼저 읽어줘. 현재 프로젝트의 목적과 하드 룰을 요약하고, 다음 작업에 필요한 기존 파일과 문서를 찾아줘. 아직 코드를 수정하지 말고 계획, 영향 범위, 검증 방법만 제안해줘.

## 3. 계획 확인

AI가 다음 내용을 포함했는지 확인한다.

- 변경할 파일
- 변경하지 않을 파일
- 사용자에게 생기는 변화
- 테스트 방법
- 민감한 정보 처리 방법
- 되돌리는 방법

## 4. 구현 후 확인

- [ ] 테스트를 실행했다.
- [ ] 변경 내용을 diff로 확인했다.
- [ ] 비밀값과 개인정보가 포함되지 않았다.
- [ ] 관련 문서를 갱신했다.
- [ ] 사용자가 직접 해야 할 일을 구분했다.
