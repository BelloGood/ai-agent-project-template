# 문서 안내판

이 문서는 AI 에이전트와 사람이 프로젝트 문서를 빠르게 찾기 위한 목차다.

| 문서 | 역할 | 작성 시점 |
|---|---|---|
| `../AGENTS.md` | AI 에이전트가 지킬 작업 규칙 | 프로젝트 시작 시 |
| `PRD.md` | 제품 목표, 사용자, 범위 | 아이디어를 정리할 때 |
| `ARCHITECTURE.md` | 시스템 구성과 데이터 흐름 | 첫 기술 설계 때 |
| `POLICY.md` | 보안·개인정보·운영 원칙 | 코드 작성 전 |
| `DESIGN_GUIDE.md` | UI·UX 규칙 | 화면 설계 전 |
| `BACKLOG.md` | 다음 작업과 완료 기준 | 항상 갱신 |
| `runbooks/` | 반복 작업 절차 | 작업을 반복하게 될 때 |

## AI에게 문서를 읽게 하는 요청

> `AGENTS.md`와 `docs/INDEX.md`를 먼저 읽어줘. 이 프로젝트의 목적과 하드 룰을 요약하고, 내가 요청한 작업과 관련된 문서를 찾아줘. 코드를 수정하기 전에는 계획과 검증 방법만 제안해줘.
